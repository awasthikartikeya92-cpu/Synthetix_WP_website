== Description ==
Agenio is a modern, premium-quality AI Agency & SaaS Wordpress Theme.It is specially designed for AI startups, SaaS companies, technology agencies, software businesses, and digital innovation teams.

== Installation ==
1. Upload the `agenio` folder to the `/wp-content/themes/` directory or install the theme through the Themes option in WordPress.
2. Activate the theme through the 'Appearance' menu in WordPress.
3. Navigate to Pages > 'Edit with Elementor Page Builder' to start customizing the pages.

For detailed instructions, refer to the [agenio Theme Documentation](https://ridhwan.gitbook.io/wordpressriver-themes-help-center).

== Frequently Asked Questions ==

= How do I import demo content? =
To import demo content, install and activate the One Click Demo Import plugin, then go to 'Appearance > Import Demo Data' and follow the instructions.
